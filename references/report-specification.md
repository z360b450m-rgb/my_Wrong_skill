# 报告与星图规范

先用脚本计算所有数字，再生成文字。禁止让语言模型自行计算题数、分数或百分比。

## 错因报告

必须包含整体指标、明确分母、知识与认知分布、错因分布、常见错误组合、代表性证据、优先建议和待复核项。多标签比例可能超过 100% 时必须披露。

## 课堂摘要

必须包含重点题目、共性问题、教学行动、课堂活动、分层指导和课后作业。经授权的校内教师报告可包含学生姓名；公开或跨机构报告必须移除姓名。

## 输出

默认面向教师只交付一个完全离线的 `教师错题分析报告.html`，其中整合整体指标、优先讲解清单、错因分布、学生情况、典型证据、待复核项目、教学建议、筛选、打印和浏览器端导出。学生情况表必须提供学生姓名下拉筛选器；待复核表必须提供学生姓名与题目两个下拉筛选器，并允许组合筛选。两个区域的筛选状态相互独立。教师必须能在待复核项目中直接录入或确认最终分数；页面按原总分与复核分数差额实时重算每名学生的最终成绩，并明确显示“可发布”或“暂不可发布”。标准 JSON、分项报告和索引属于内部或按需输出，不默认交付给教师。

薄弱知识点和主要错因使用横向数量柱状图：当前分布中的最大数量为满宽，其余柱长严格按 `数量 / 当前最大数量` 缩放，同时显示数量与占比。不得使用会被严格 CSP 拦截的内联 `style` 计算柱长。

复核决定保存在当前浏览器，并能导出为复核记录；最终成绩能直接导出为 CSV。学生情况表显示复核前完整、去重并按试卷顺序排列的错题题号；最终成绩表按教师复核决定实时更新错题题号，某题被改为满分时移除，低于满分时保留。最终成绩表与最终成绩 CSV 均按复核后的实际得分从低到高排列，同分时按稳定学生标识排列。待复核表只显示当前复核题目，不重复展示全部错题题号。只有一名学生的待复核数与未评分数都为零时，其成绩才可标记为可发布。教师端不得暴露数据库、命令行或原始 JSON 操作；需要持久化到校务系统时，由独立适配器消费导出的复核记录。

学生情况使用 `student_name` 展示，并在内部继续使用 `student_ref` 关联。汇总已评分得分与分母、得分率、错题数、未评分数、待复核数、主要错因和薄弱知识点。得分率只使用已评分题目的满分作为分母；未评分题目必须单独披露。不得从作答推断态度、能力、动机或其他人格结论。

教师 HTML 必须由 `teacher-report` 固定入口生成。Agent 只生产或补充标准分析数据，不决定布局、颜色、组件或展示字段。渲染链路使用版本化 Teacher Report View、稳定键排序、确定性列表排序和锁定模板；同一分析输入、同一版本必须产生相同的 `output_sha256`。命令返回的清单必须包含视图版本、渲染器版本、模板版本、模板哈希和输出哈希。

禁止直接向渲染器传入原始答卷，禁止模板计算统计，禁止 Agent 添加自定义面板。模板发生任何变化时，必须显式升级模板版本和哈希并通过一致性测试。

- 标准 v2 JSON
- 复核队列 JSON
- 错因报告 Markdown/HTML
- 课堂摘要 Markdown/HTML
- 星图 JSON 和完全离线的交互 HTML

HTML 不引用 CDN，不执行输入脚本，必须转义所有题干、OCR、证据和标签文本，并配置严格 CSP。

## 星图协议

包含 `schema_version`、`analysis_id`、`aggregation`、`layout_seed`、`index_version`、`nodes`、`edges`、`filters` 和结构化 `legend`。节点大小表示失分，颜色表示主知识点，边表示关系相似度；班级图只使用匿名聚合数据。

索引已建立时，将索引命令返回的版本传给 `graph --index-version <id>` 或 `report --index-version <id>`；只有尚未建立索引时才使用 `unindexed`。
